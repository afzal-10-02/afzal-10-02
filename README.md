### 🏫 Campus Hire — Placement Management Portal

A university placement-drive management platform designed to replace manual spreadsheets, emails and fragmented placement workflows.

**Built with:**

`Flask` `Vue.js` `SQLite` `SQLAlchemy` `Redis` `Celery` `JWT` `Bootstrap`

**Key features:**

* 👨‍💼 Admin management
* 🏢 Company and placement-drive management
* 🎓 Student applications
* 🔐 Role-based authentication
* ⚡ API response caching with Redis
* 🔄 Background/batch processing with Celery
* 🗄️ Relational database design
* 🌐 REST API architecture

🔗 **Repository:**
